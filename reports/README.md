# Numerical reports

These files describe the public numerical reproduction. Manuscripts, reviewer correspondence and internal revision records are excluded.

- [Results and scientific identifiers](results.md)
- [Installation, stages and output interpretation](reproduction.md)
- [Frozen input and output hashes](reproduction_manifest.json)
- [Public-export verification receipt](verification.json)
- [Original operating points](historical_operating_points.csv)
- [Matched-membership operating points](matched_operating_points.csv)
- [Quantile operating points](quantile_operating_points.csv)
- [Diagnostic operating points and achieved alarms](diagnostic_operating_points.csv)
- [Diagnostic condition-level counts, delays, gains and losses](diagnostic_condition_summary.csv)

The CSVs are byte-identical copies of their frozen analysis outputs. The dated experiment paths in the reproduction manifest are retained scientific identities. Generated full results live under an ignored fresh output directory.
